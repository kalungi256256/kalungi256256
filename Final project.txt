Program tittle:   Personal finance Tracker and Budget Analyzer.

Description:

        Many college students and  young adults struggle with managing their personal finances effectively. They often don't have a clear  picture of where their money goes each month,
    making it hard to save for important goals and avoid overspending. While there are commercial aaps available,they can be complex,expensive or require sharing sensitive financial information with third parties.
    My program will solve this real-world problem by creating a comprehensive personal finance tracker, that helps the users monitor their  income, expenses and saving goals.

learning Objectives:

    File Operations: Reading and writing CSV files containing financial transaction data.

    Data Processing: Parsing, cleaning, and organizing financial data from multiple sources.

    Dictionary and List Management: Using complex data structures to store and manipulate financial records.

    Mathematical Calculations: Computing percentages, averages, totals, and budget variances.

    Date and Time Handling: Working with transaction dates to generate monthly/yearly reports.

    Function Design: Creating modular, reusable functions that each perform specific financial calculations.

    Error Handling: Managing file errors, data format issues, and invalid user inputs.

    Data Visualization: Creating simple text-based charts and reports for financial analysis.

    Algorithm Development: Implementing categorization logic and budget recommendation algorithms.

    Testing and Validation: Writing comprehensive test functions to ensure financial calculations are accurate.

Modules Used:

    Csv: Reading and writing financial transaction data from csv files.

    Datetime: Handling transaction dates and generating time-based reports.

    os: file system operations and checking file existence.

    statistics: Calculating averages,medians and other statistical measures for spending analysis.

    Math: Perfoming financial calculations like compound interest and percentage calculations.


Function names:

Data Management Functions:

    load_transactions(filename): Read transaction data from CSV files.

    save_transactions(transactions, filename): Write processed transactions to file.

    load_categories(filename): Load expense category definitions.

    ave_user_preferences(preferences, filename): Store user settings and budget goals.

Data Processing Functions:

    categorize_transaction(description, amount, categories): Automatically assign categories to transactions.

    filter_transactions_by_date(transactions, start_date, end_date): Filter transactions for specific time periods.

    calculate_monthly_totals(transactions): Compute monthly income and expense totals.

    identify_recurring_transactions(transactions): Find regular income/expense patterns.

Analysis Functions:

    alculate_budget_variance(actual_expenses, budgeted_amounts): Compare actual vs. planned spending.

    analyze_spending_trends(transactions, months): Identify spending pattern changes over time.

    calculate_savings_rate(income, expenses): Determine percentage of income saved.

    generate_category_breakdown(transactions): Calculate spending by category.

Reporting Functions:

    generate_monthly_report(transactions, month, year): Create detailed monthly financial summary.

    create_spending_chart(category_totals): Generate text-based visualization of spending.

    recommend_budget_adjustments(spending_analysis): Suggest budget improvements.

    display_financial_summary(income, expenses, savings): Show overall financial health.

Utility Functions:

    validate_transaction_data(transaction): Check data integrity and format.

    format_currency(amount): Display monetary amounts consistently.

    get_user_budget_input(): Collect budget goals from user.

    main(): Coordinate program execution and user interaction.


Test function names:

    test_calculate_savings_rate(): Test savings percentage calculations.

    test_categorize_transaction(): Verify automatic transaction categorization logic.

Data Processing Tests:
